This repository features multiple university projects 

**QT**

*AckermanFunc* - features visual implementation of Ackermann function

*Algorithms* - implements algorithms of reversing digit order in numbers, converting decimal number to binary, solving hanoi towers and counting all subfolders of a given folder

*MyQtPaint* - Application that resembles MS Paint, allows to draw with vector-like shapes

*OrderMahagerProject* - simple file management project, generates invoices based on order details

*SimpleAnimation* - features basic animated objects 

*StringDemonstration* - uses Qt's UI to demonstrate various string functions in c++

*TypingTrainerProject* - simple project that helps user improve typing skills, features file management and input control

*WorkingWithLibrary* - implements own version of std::vector and builds it into a library in QT


**C++**

*MyDataStructures* - implements my Queue, Binary Tree, Hash Table

*MyComplexDataStructures* - implements my BST, ListHeap and ArrayHeap
